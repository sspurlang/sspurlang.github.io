SSPUR

A programming language for AI agents to write, read and maintain.

Statically typed and effect-tracked. Contracts are checked at run time, fuzzed and proved, and it compiles to native code that runs faster than idiomatic C++ with the same safety checks.

Get started Try it in the playground

Install

macOS, Linux and Windows, on arm64 and x86_64. Native compilation uses clang.

macOS, with Homebrew

brew install utkarshavardhana/sspur/sspur

Linux and macOS, with the install script

curl -fsSL https://github.com/sspurlang/sspur/releases/latest/download/install.sh | sh

It verifies the release's SHA-256 checksum and installs sspur into ~/.local/bin.

Windows, in PowerShell

irm https://github.com/sspurlang/sspur/releases/latest/download/install.ps1 | iex

It verifies the checksum, installs sspur.exe and adds it to your user PATH. Native compilation needs LLVM and the Visual Studio Build Tools.

Why SSPUR

Native speed

0.14xthe time of idiomatic C++ on records, lists and trees, and below 1x on all seven benchmark workloads

An optimizing native compiler, with C++ at clang -O2 and the same safety checks on both sides. Overflow, out-of-bounds access and contract violations always trap; the compiler proves most of those checks away, reuses memory in place and fuses pipelines into single loops.

Native benchmarks

Effects and contracts

Every side effect is in the signature, so a reviewer can see what a function may do:

fn save(u: User) -> Unit ! db.write, log

pre, post and refinement types like Int where _ > 0 are checked at run time, turned into property tests by the fuzzer and proved with Z3 where possible.

Standard library

Made for agents

0.67xthe tokens of Python on 17 multi-step coding tasks, every hidden test passing

Atomic edits that typecheck the whole codebase, typed holes that fill themselves, an MCP server, a language server and editor support from VS Code to Zed.
